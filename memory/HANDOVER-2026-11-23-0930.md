## Key Decisions Made
- **Nexuses live in `meta.magic.ley`.** `buildInfrastructure` only has the layout, `layout.field` is a function that
  JSON and year frames drop, and `frameAt` keeps `meta`. So the field-only half runs in `generateCity`.
- **Grid-defined nexuses kept for chords.** The chord 432+540 count does not converge (220: 65 … 660: 75) while
  supply moves 0.1 %; misses are near-cut peaks and pairs under three cells apart. The test claims "none missed"
  only for single frequencies and checks the chord's misses are of those two kinds.
- **Closed Gabriel disc** (planar on symmetric plates); measured cities agree with the open rule (47 lines default).
- **Version numbering:** 1.7.0 = 7a, 1.7.1 = 7b; each later contract-changing stage bumps the patch.
- **`ley-n1`** scores losing nexus 0 (strongest) and the busiest line; stranded = shortfall beyond the plant ÷ demand.
