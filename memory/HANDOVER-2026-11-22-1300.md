## Session Summary
The independent review of 2026-11-19 failed Phase 6 on one blocking finding: the page and the CLI wrote
different bytes, because Node and Chromium differ in the last bit of `Math.sin`, `exp`, `pow` and the rest.
This session fixed that and every should-fix and nit, on `claude/phase6-export` (PR #2). Supersedes
`HANDOVER-2026-11-11-1844.md`. The review itself is the Project note "Phase 6 independent review".

## What Was Done
- `src/detmath.js`: deterministic sin, cos, atan, atan2, asin, acos, exp, log, log2, pow, hypot (fdlibm
  algorithms from exact operations). Every `src/` stage calls `DM.*`; `build.mjs` bundles it first.
- `test/detmath.test.mjs` (pinned fingerprint, one-ulp accuracy, edge cases, a scan that forbids platform
  calls in `src/`) and `test/page.test.mjs` (Chromium = Node at every stage; page saves regenerate byte for
  byte from `profile.json`, plan and year).
- `meta.horizon` on year frames; the page writes `year` into the profile; the CLI reads it.
- glTF foundations and a size-aware ground grid; quaternions 1e-9, translations 0.1 mm.
- GeoJSON drops collapsed lines. CLI: `metrics --year`, `-` for stdin and stdout, idle flags refused,
  `--infra` governs networks in year exports.
- Golden hashes re-recorded once. Docs: CHANGELOG, README, CLAUDE.md, spec "As built", eval header.

## Key Decisions Made
- **Own math module rather than "same runtime only".**
  - **Rationale**: the README's promise and the Phase 8 shared profile both need page = CLI. Cost measured:
    generate 0.82 s vs 0.76 s; commuting model within noise.
- **Fingerprint as the contract.** `fingerprint()` hashes the module's bits; pinned in Node, compared in
  Chromium. Changing it is a version bump with re-recorded goldens.
- **Byte comparisons never use `deepEqual`.** Two megabyte arrays that differ ran the test process out of
  memory (SIGKILL) instead of failing; `sameBytes` in `test/formats.test.mjs` reports file and offset.
- **`meta.horizon`: yes**, folded into unreleased 1.6.0; `opts.horizon` removed from the exporters.

## Pitfalls & Gotchas
- This work was lost once before (2026-10-17 workspace reset) and sat uncommitted for hours on 2026-11-22.
  **Commit and push as soon as the affected suites pass.**
- `build.mjs` strips only single-line imports; every `src/` file imports `DM` on one line (tested).
- The page test takes about four minutes and needs Playwright with a Chromium; it skips without one, so a
  green suite on a machine without Chromium has not proved page = CLI.
- Timing under load is noisy here: the commuting model measured 3.6–5.9 s both before and after.
- A one-ulp change to `exp`'s smallest coefficient changes no output bit: an equivalent mutant.
- Building `cjval` and running a downloaded Godot binary are blocked in this cloud session (the reviewer's
  session had `cjval`).
