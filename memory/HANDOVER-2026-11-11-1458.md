## Key Decisions Made
- **Decision**: hand-rolled MCP server, no SDK.
  - **Context**: mcp-builder recommends the TypeScript SDK.
  - **Rationale**: the engine is dependency-free by design; the server is ~80 lines of JSON-RPC over
    `agentTools()`. Revisit only if HTTP transport or resources are needed.
- **Decision**: MCP results return text only, no `structuredContent` copy.
  - **Rationale**: a duplicate payload doubles what the client puts in context.
- **Decision**: CLI named `export` now; Phase 6 adds `generate` as the documented name with `export` as alias.
  - **Rationale**: ROADMAP names `cymatic generate … --out city.gltf`; that command's semantics (`--year`)
    are not settled yet, so the name is reserved for Phase 6.
- **Decision**: no `src/` changes this session.
  - **Rationale**: everything here is tooling around the engine; contract and determinism stay untouched,
    so `ENGINE_VERSION` stays 1.5.0.
- **Decision**: CLAUDE.md points at README sections by heading, not line numbers.
  - **Rationale**: line numbers went stale within the session after the README edit.

## Pitfalls & Gotchas
- **Year depends on horizon (measured).** `simulate()` schedules growth to finish the plan at `years`, so the
  state at year 80 of an 80-year run (town 432 Hz: 1,063 buildings) differs from year 80 of a 100-year run
  (494). `--year` needs `--horizon`. Viewer horizon field defaults to 120; `simulate()` defaults to 100.
- Keyframes land only at `years·(k+1)/K`; arbitrary years need a `stateAt` refactor.
- The 432 Hz default city has no `core`-zone buildings (residential 5,567, mixed 914).
- Suites are slow serially (city 102 s, infrastructure 69 s, chord 64 s, terrain 51 s, people 32 s,
  query 23 s, simulation 22 s); `node --test` runs files in parallel.
- `build.mjs` inlines `src/` only; `bin/` is outside the viewer bundle.
- `docs/research-report.md` is listed in `.gitignore`.
